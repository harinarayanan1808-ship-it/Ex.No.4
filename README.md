## Procedure:

### 1. Define the Scenario and Use Case

**Use Case:** AI-Based Student Course Management System

**Scenario:**

A college plans to implement an AI-based Student Course Management System to automate academic activities such as student registration, attendance tracking, course enrollment, assignment management, examination results, and communication between students and faculty. The AI system provides intelligent recommendations, generates reports automatically, and reduces manual work.

**Target Audience:**

- Students
- Faculty Members
- College Administrators
- Examination Cell

**Main Objectives:**

- Automate student record management.
- Improve attendance monitoring.
- Simplify course registration.
- Generate academic reports automatically.
- Reduce paperwork and human errors.
- Improve communication between students and faculty.
- Save time by automating repetitive tasks.

---

## 2. Prompt Patterns for Each Design Aspect

### A. Comparative Analysis Prompt

**Definition:**
A Comparative Analysis Prompt compares two or more concepts by identifying their similarities and differences.

**Prompt:**

"Compare the traditional Student Course Management System with an AI-based Student Course Management System in terms of efficiency, accuracy, cost, report generation, and user experience."

### Output:

| Feature | Traditional System | AI-Based System |
|---------|--------------------|-----------------|
| Record Management | Manual | Automated |
| Accuracy | Moderate | High |
| Report Generation | Time-consuming | Instant |
| Attendance Tracking | Manual | Automatic |
| User Experience | Basic | Interactive |
| Error Rate | High | Low |
| Cost | Lower initially | Higher initially but cost-effective in the long run |
| Decision Support | Not available | AI-based recommendations |

**Evaluation:**
The AI-based system performs better in automation, accuracy, and report generation while reducing manual effort.

---

### B. Experiential Perspective Prompt

**Definition:**
This prompt asks the AI to answer from the perspective of a specific user or role.

**Prompt:**

"As a final-year college student, explain your experience using an AI-powered Student Course Management System throughout one semester."

### Output:

The AI-based Student Course Management System made my academic activities much easier. I could register for courses online, receive reminders about assignment deadlines, check attendance instantly, and download my semester results without visiting the college office. The chatbot answered common questions quickly, and personalized course recommendations helped me choose electives. Overall, it saved time and improved my learning experience.

**Evaluation:**

The response clearly explains the student's experience and highlights practical benefits.

### E. Prompt Size Limitations

**Definition:**
Large prompts should be divided into smaller prompts to improve response quality.

### Large Prompt:

"Generate a complete report containing student records, attendance, faculty details, course information, examination schedules, grades, fee details, department statistics, and semester performance for the entire college."

### Problem:

- Too much information in one request.
- Response may become incomplete.
- Increased processing time.

### Refined Prompt:

Prompt 1:
"Generate the student records department-wise."

Prompt 2:
"Generate attendance reports for 100 students at a time."

Prompt 3:
"Generate examination reports semester-wise."

Prompt 4:
"Generate fee reports separately."

Prompt 5:
"Generate faculty workload reports."

### Evaluation:

Breaking the prompt into smaller tasks improves response quality, accuracy, readability, and reduces processing time.
